今日はあと何%? 今年は? あなたの人生は?

UNTILは、その答えをホーム画面、ロック画面、Apple Watchに表示します。アプリを開かなくても、スマートフォンを手に取るたびに残り時間が目に入ります。

ウィジェット
• 日・月・年・人生:割合と残り時間
• 期限:大切な日までの日数
• カウンター:タップで+1(水、ページ、運動、なんでも)
• 時間タイマー:タップで開始と停止
• 今日のタスクをひと目で
• 次の期限:近い順に3件(Premium)

週で見る人生
生年月日を入れると、人生全体が週のマス目で表示されます。時間には限りがあること、そして今日が大切であることを、静かにはっきりと思い出させてくれます。

手首とアイランドに
• Apple Watch:文字盤に今日の%、手首にTime Hub
• Dynamic IslandとLive Activity(対応するiPhone、Premium)

無料
• 日と年のウィジェット
• Apple Watchの今日の%
• 最初の期限と最初のカウンター
• 毎日のタスク、連続記録、バッジ、シェア

PREMIUM
• 月と人生のウィジェット、週で見る人生の全画面
• 最大20件の期限とカウンター、次の期限ウィジェット
• Dynamic IslandとLive Activity
• ウィジェットの追加カスタマイズ
5日間、すべて無料でお試しいただけます。お試し期間中に料金は発生せず、自動更新もされません。その後のPremiumは、週・月・年のサブスクリプション、または買い切りです。サブスクリプションは解約するまで更新されます。管理はApple IDの設定から行えます。

広告はありません。UNTILは時間への気づきのためのアプリで、騒がしいToDoリストではありません。残りを確かめたら、また一日に戻りましょう。
